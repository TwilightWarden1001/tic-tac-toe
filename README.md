# React Tic-Tac-Toe

A fully functional tic-tac-toe game built with React, featuring game state management, winner detection, and time-travel functionality to review previous moves.

## Features

- Two-player gameplay (X and O)
- Automatic winner detection for all win conditions
- Draw detection when board is full
- Time-travel feature to jump to any previous move
- Clean, responsive UI

## How to Run

1. Clone the repository:

```bash
   git clone https://github.com/TwilightWarden/tic-tac-toe.git
   cd tic-tac-toe
```

2. Install dependencies:

```bash
   npm install
```

3. Start the development server:

```bash
   npm start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
